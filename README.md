# MINIX 3.4.0rc6 — amd64 UEFI branch

This repository is a fork of https://github.com/nnonaka/minix/ with UEFI
boot support and an x86_64 (amd64) port.

## Build environment

The cross-build environment is Ubuntu 26.04. Fetch the texinfo and binutils
sources required by the toolchain before building.

## Build an amd64 UEFI installation ISO

Build the release sets first, then create the ISO:

```sh
./build.sh -U -u -m amd64 -O ../build release
sudo apt install xorriso
OBJ=../build CREATE_IMAGE_ONLY=1 bash releasetools/x86_64_uefi_cdimage.sh
```

The resulting image is:

```
../build/releasedir/images/Minix-3.4.0rc6-x86_64-install.iso
```

The script builds a FAT32 EFI El Torito boot image containing
`EFI/BOOT/BOOTX64.EFI`, and an ISO9660 filesystem containing the amd64
kernel, boot modules, boot menu and release sets. The boot menu uses the
64-bit UEFI loader and the Multiboot2 entry point; this is not the legacy
32-bit BIOS image generated by `releasetools/x86_cdimage.sh`.

The ISO can also be generated from existing build outputs by setting
`CREATE_IMAGE_ONLY=1` (the default). Set `CREATE_IMAGE_ONLY=0` to invoke
the release build before packaging. Paths and image settings can be
overridden with `OBJ`, `DESTDIR`, `RELEASEDIR`, `SETS_DIR`,
`CROSS_TOOLS`, `WORK_DIR`, `IMG`, `XORRISO`, and `EFIMB`.

### Installer scope

This change makes a bootable amd64 UEFI installation CD and bundles the
release set archives in `/usr/amd64/binary/sets`. It boots MINIX from the CD
so the system and set archives are available for installation or recovery.
It does **not** add an unattended installer or a new interactive UEFI/GPT
partitioning front end; that remains separate work (the existing
`distrib/amd64/installimage` uses the older `sysinst` path).

## Existing amd64 live image

```sh
./build.sh -U -u -m amd64 -O ../build live-image
```

The live disk image is produced under
`../build/distrib/amd64/liveimage/emuimage/`.

## Current port status

- i386 and amd64 source/build support.
- UEFI boot via `bootia32.efi` and `bootx64.efi`.
- Multiboot2 kernel boot and login prompt on the tested live image.
- POSIX test status recorded by the port author: 94/97 passed.

The amd64 port and the installation media are experimental; test the ISO in
a VM before writing it to physical media.
